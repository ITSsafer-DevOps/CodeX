  <h2 style="font-size: 1.5rem; font-weight: 600; color: #f3f4f6;">Popis 📝</h2>
  <p style="text-align: justify; margin-top: 10px;">CodeX je jednoduchá Android aplikácia slúžiaca ako terminálová substitučná šifra. Jej hlavnou funkciou je šifrovať text zadaný používateľom. UI má moderný, nadčasový terminálový dizajn, pričom interaktívny vstup je inšpirovaný <strong>Kali Linuxom</strong> a výstup <strong>Ubuntu Linuxom</strong>.</p>
  
  <div style="border-bottom: 2px solid #333; margin-top: 30px; margin-bottom: 20px;"></div>

  <h2 style="font-size: 1.5rem; font-weight: 600; color: #f3f4f6;">Funkcionalita ✨</h2>

    <li style="margin-bottom: 10px;"><span style="color: #FF3131; font-weight: bold;">•</span> <span style="font-weight: 500;">Substitučná šifra:</span> Šifruje text podľa substitučného pravidla.</li>
    <li><span style="color: #FF3131; font-weight: bold;">•</span> <span style="font-weight: 500;">Terminálové rozhranie:</span> Intuitívny vstup a výstup v reálnom čase v terminálovom štýle.</li>

  <h2 style="font-size: 1.5rem; font-weight: 600; color: #f3f4f6;">Description 📝</h2>
  <p style="text-align: justify; margin-top: 10px;">CodeX is a simple Android application that serves as a terminal-based substitution cipher. Its primary function is to encrypt user-entered text. The user interface features a modern, timeless terminal design, with the interactive input inspired by <strong>Kali Linux</strong> and the output by <strong>Ubuntu Linux</strong>.</p>
  
  <div style="border-bottom: 2px solid #333; margin-top: 30px; margin-bottom: 20px;"></div>

  <h2 style="font-size: 1.5rem; font-weight: 600; color: #f3f4f6;">Functionality ✨</h2>
  <ul style="list-style-type: none; padding-left: 0;">
    <li style="margin-bottom: 10px;"><span style="color: #FF3131; font-weight: bold;">•</span> <span style="font-weight: 500;">Substitution Cipher:</span> Encrypts text based on a unique substitution rule.</li>
    <li><span style="color: #FF3131; font-weight: bold;">•</span> <span style="font-weight: 500;">Terminal Interface:</span> Intuitive input and real-time output in a classic terminal style.</li>
  </ul>
  
  <div style="border-bottom: 2px solid #333; margin-top: 30px; margin-bottom: 20px;"></div>

  <h2 style="font-size: 1.5rem; font-weight: 600; color: #f3f4f6;">Installation ⬇️</h2>
  <p style="text-align: justify; margin-top: 10px;">This repository contains compiled Android Application Package (<strong>APK</strong>) files for CodeX. The source code for this project is <strong>not public</strong>.</p>
  <p style="text-align: justify; margin-top: 10px;">To install CodeX on your Android device:</p>
  <ol style="list-style-type: decimal; padding-left: 20px;">
    <li style="margin-bottom: 10px;">Go to the <a href="https://github.com/ITSsafer-DevOps/CodeX/releases" style="color: #FF3131; text-decoration: none;">Releases section</a> of this repository.</li>
    <li style="margin-bottom: 10px;">Download the desired APK file (e.g., <code>CodeX-4.0.apk</code>).</li>
    <li>Install the APK. You might need to enable "Install from unknown sources" in your device's settings.</li>
  </ol>

  <div style="border-bottom: 2px solid #333; margin-top: 30px; margin-bottom: 20px;"></div>

  <h2 style="font-size: 1.5rem; font-weight: 600; color: #f3f4f6;">Development Journey 🚀</h2>
  <p style="text-align: justify; margin-top: 10px;">This repository includes four compiled APK versions of CodeX, ranging from <code>CodeX-1.0.apk</code> to <code>CodeX-4.0.apk</code>. These different versions demonstrate the evolution of the application's user interface, showcasing its progression from initial basic layouts to the final modern terminal design. The core cipher logic remains consistent across all versions. <code>CodeX-4.0.apk</code> represents the latest and most refined design.</p>
  
  <div style="border-bottom: 2px solid #333; margin-top: 30px; margin-bottom: 20px;"></div>

  <h2 style="font-size: 1.5rem; font-weight: 600; color: #f3f4f6;">Usage 💡</h2>
  <ul style="list-style-type: none; padding-left: 0;">
    <li style="margin-bottom: 10px;"><span style="color: #FF3131; font-weight: bold;">•</span> Launch the app.</li>
    <li style="margin-bottom: 10px;"><span style="color: #FF3131; font-weight: bold;">•</span> Type your text into the upper (Kali-inspired) terminal.</li>
    <li><span style="color: #FF3131; font-weight: bold;">•</span> See the encrypted output in the lower (Ubuntu-inspired) terminal.</li>
  </ul>
